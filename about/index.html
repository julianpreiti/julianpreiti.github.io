About

I'm a backend-oriented full-stack developer with a Systems Analyst background — that's where I learned to treat software as a way to fix broken processes, not just ship features. It started with turning repetitive Zendesk tickets and network-ops workflows into scripts and integrations, and it's the same instinct I bring to development now.

I build with Java and Spring Boot on the backend, React on the frontend, and I'm comfortable owning a problem end to end — from the data model to the API to the interface people actually use.
